# Project Recreation Prompt

## Overview
Recreate a complete Next.js website called "mmt-ow" — a personal portfolio/studio site for a team called "Mad Mob Team" based in Sulaymaniyah. The design language is **brutalist**: heavy black borders, high-contrast black/white/red color scheme, skewed transforms, monospace fonts, and aggressive typographic styling.

## Tech Stack & Dependencies

Install these exact dependencies:

```bash
npx create-next-app@16.3.5 mmt-ow --typescript --tailwind --eslint --app --src-dir=false --import-alias="@/*"
cd mmt-ow
npm install next@16.3.5 react@19.2.8 react-dom@19.2.8
```

### 11. `app/[locale]/layout.tsx`
```tsx
import type {Metadata} from 'next';
import {Space_Mono} from 'next/font/google';
import {NextIntlClientProvider} from 'next-intl';
import {getMessages} from 'next-intl/server';
import {hasLocale} from 'next-intl';
import {notFound} from 'next/navigation';
import {routing} from '@/i18n/routing';
import "../globals.css";

const spaceMono = Space_Mono({
  subsets: ["latin"],
  weight: ["400", "700"],
  variable: "--font-space-mono",
});

export const metadata: Metadata = {
  title: "mmt-ow",
  description: "",
};

export default async function LocaleLayout({
  children,
  params
}: {
  children: React.ReactNode;
  params: Promise<{locale: string}>;
}) {
  const {locale} = await params;
  if (!hasLocale(routing.locales, locale)) {
    notFound();
  }

  const messages = await getMessages();
  const dir = locale === 'ar' || locale === 'ckb' ? 'rtl' : 'ltr';

  return (
    <html lang={locale} dir={dir}>
      <body className={spaceMono.variable}>
        <NextIntlClientProvider messages={messages}>
          {children}
        </NextIntlClientProvider>
      </body>
    </html>
  );
}
```

```ts
import {getRequestConfig} from 'next-intl/server';
import {hasLocale} from 'next-intl';
import {routing} from './routing';

export default getRequestConfig(async ({requestLocale}) => {
  let locale = await requestLocale;

  if (!locale || !hasLocale(routing.locales, locale)) {
    locale = routing.defaultLocale;
  }

  return {
    locale,
    messages: (await import(`../messages/${locale}.json`)).default
  };
});
```

### 22. `app/components/Navbar.tsx`
This is the main navigation component with a settings dropdown. It must be a client component (`"use client"`). It displays:
- A logo link (styled with heavy borders and skew transforms)
- Navigation links: Projects, About, Contact
- A Settings dropdown button that opens a panel with:
  - Theme section: "Brutalistic" and "Minimalistic" clickable spans (non-functional, just UI)
  - Font size section: "Sm", "Md", "Lg" clickable spans (non-functional)
  - Language section: En, Ar, Kur buttons that switch locale using `useRouter`
- Mobile hamburger menu toggle
- All styling: `bg-black` background, `border-white` borders, `text-white` text, hover effects invert colors (`hover:bg-white hover:text-black`), heavy `skewX` transforms on elements
- The settings dropdown uses `visible opacity-100` when open and `invisible opacity-0` when closed
- Use `Bars3Icon` and `XMarkIcon` from `@heroicons/react/24/outline`
- Import `useTranslations` from `next-intl` for all text

```tsx
"use client";

import { useState } from "react";
import { useTranslations } from "next-intl";
import { useRouter, usePathname } from "@/i18n/navigation";
import { Bars3Icon, XMarkIcon } from "@heroicons/react/24/outline";

function SettingsContent() {
  const t = useTranslations("Settings");

  return (
    <div className="w-full">
      <div className="mb-3 border-b-2 border-white pb-2 font-[family-name:var(--font-space-mono)] text-xs font-bold uppercase tracking-widest text-white">
        {t("theme")}
      </div>
      <div className="mb-3 flex gap-2">
        <span className="cursor-pointer border-2 border-white px-2 py-0.5 font-[family-name:var(--font-space-mono)] text-xs text-white transition-all hover:bg-white hover:text-black">
          {t("brutalistic")}
        </span>
        <span className="cursor-pointer border-2 border-white px-2 py-0.5 font-[family-name:var(--font-space-mono)] text-xs text-white transition-all hover:bg-white hover:text-black">
          {t("minimalistic")}
        </span>
      </div>
      <div className="mb-3 border-b-2 border-white pb-2 font-[family-name:var(--font-space-mono)] text-xs font-bold uppercase tracking-widest text-white">
        {t("fontSize")}
      </div>
      <div className="mb-3 flex gap-2">
        <span className="cursor-pointer border-2 border-white px-2 py-0.5 font-[family-name:var(--font-space-mono)] text-xs text-white transition-all hover:bg-white hover:text-black">
          {t("sm")}
        </span>
        <span className="cursor-pointer border-2 border-white px-2 py-0.5 font-[family-name:var(--font-space-mono)] text-xs text-white transition-all hover:bg-white hover:text-black">
          {t("md")}
        </span>
        <span className="cursor-pointer border-2 border-white px-2 py-0.5 font-[family-name:var(--font-space-mono)] text-xs text-white transition-all hover:bg-white hover:text-black">
          {t("lg")}
        </span>
      </div>
      <div className="border-b-2 border-white pb-2 font-[family-name:var(--font-space-mono)] text-xs font-bold uppercase tracking-widest text-white">
        {t("language")}
      </div>
      <LanguageButtons />

  );

function LanguageButtons() {
  const router = useRouter();
  const pathname = usePathname();

  function switchLocale(locale: string) {
    router.replace(pathname, {locale});
  }

  return (
    <div className="mt-2 flex gap-2">
      <button onClick={() => switchLocale("en")} className="cursor-pointer border-2 border-white px-2 py-0.5 font-[family-name:var(--font-space-mono)] text-xs text-white transition-all hover:bg-white hover:text-black">En</button>
      <button onClick={() => switchLocale("ar")} className="cursor-pointer border-2 border-white px-2 py-0.5 font-[family-name:var(--font-space-mono)] text-xs text-white transition-all hover:bg-white hover:text-black">Ar</button>

    </div>
  );
}
```

## Design Specifications (Critical - Follow Exactly)

### Design Language: Brutalist
- **Background**: Primary is black (`bg-black`), secondary is white (`bg-white`) or neutral tones (`bg-neutral-100`, `bg-neutral-900`)
- **Borders**: Heavy white borders (`border-white`, `border-4`, `border-b-4`) on black backgrounds; black borders (`border-black`) on white backgrounds
- **Typography**: Space Mono font (via `next/font/google`), all-caps, extra-bold (`font-black`), aggressive letter spacing (`tracking-widest`, `tracking-tighter`)
- **Colors**: Black (#000), White (#fff), Red (#dc143c via `red-600`), Neutral grays (`neutral-100`, `neutral-400`, `neutral-500`, `neutral-800`, `neutral-900`)
- **Skew transforms**: Heavy `skewX` on logo and headings (`skewX(-6deg)` on container, `skewX(6deg)` on inner span to counteract)
- **Shadows**: Offset box shadows like `shadow-[10px_10px_0_0_#333]` and `shadow-[6px_6px_0_0_#fff]` — hard-edged, no blur
- **Hover effects**: Elements translate negatively (`hover:translate-x-[-4px]`, `hover:translate-y-[-4px]`) and swap background/text colors
- **Mobile**: Hamburger menu, collapsible sections with `max-h` transitions
- **RTL**: Arabic (`ar`) and Kurdish (`ckb`) locales use `dir="rtl"`, English uses `dir="ltr"`

### Font
- Import `Space_Mono` from `next/font/google` with subsets `["latin"]`, weights `["400", "700"]`, and CSS variable `--font-space-mono`
- Apply the variable as `className={spaceMono.variable}` on the `<body>` element
- All body text uses `font-[family-name:var(--font-space-mono)]`

### i18n Setup
- Use `next-intl` for internationalization
- 3 locales: `ckb` (Kurdish, default), `en` (English), `ar` (Arabic)
- Arabic and Kurdish use RTL layout
- Message files in `/messages/` directory with JSON structure matching the translations shown above
- Navigation uses `useRouter`, `usePathname` from `@/i18n/navigation`

## Setup Instructions

1. Run `npm install` to install all dependencies
2. Run `npm run dev` to start the development server on port 3000
3. The site should be fully functional with:
   - Locale switching (En/Ar/Kur) in the Settings dropdown
   - Navigation links working
   - All pages rendering correctly
   - RTL support for Arabic and Kurdish
   - Brutalist visual design throughout
4. Run `npm run build` to verify the production build succeeds

## Key Architecture Notes

- All page files use the `"use client"` directive only where interactivity is needed (Navbar is client-side)
- `app/layout.tsx` is a minimal wrapper that just returns children (Next.js App Router root layout)
- `app/[locale]/layout.tsx` handles locale, RTL direction, font loading, and i18n provider wrapping
- The `app/[locale]/` structure means all pages are locale-prefixed (`/en/projects`, `/ar/about`, etc.)
- The `proxy.ts` file handles middleware for locale routing
- All translations come from JSON message files
- The design uses NO CSS modules, NO CSS-in-JS libraries — only Tailwind utility classes and inline `style` attributes for skew transforms
